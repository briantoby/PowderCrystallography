# PowderCrystallography
A draft for an open-access textbook on Powder Diffraction Crystallography and GSAS-II. 

At this stage I am posting the first complete draft of the book as a "preview version" (edition 0.9), since it will take me some time to give it a full review. 
Once that is done I will create the first edition. I'm not sure I will ever consider this project as "done", however. 

To download a copy, open the [releases page](https://github.com/briantoby/PowderCrystallography/releases/latest) and download the PDF file. There is an [HTML version](https://briantoby.github.io/PowderCrystallography/HTML-template.html) but this was generated more for machine-learning applications and is probably not as well formatted as the PDF.
