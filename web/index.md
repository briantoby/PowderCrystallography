## *Crystallographic Powder Diffraction Analysis with GSAS-II: An Introduction to Rietveld Analysis*, an open-access textbook from Brian H. Toby


The [GitHub repository](https://github.com/briantoby/PowderCrystallography) 
associated with this website contains an open-access textbook on 
powder diffraction crystallography and GSAS-II,
titled *Crystallographic Powder Diffraction Analysis with GSAS-II: An Introduction to Rietveld Analysis*. 
The book is far from finished, but the initial set of ~30 chapters is done. The current version has not been proofread, but
I am making it available as a "preview version" (edition 0.9), since it will 
take me some time to complete the review and I think it has value in the current form.
Once that review is done, I will create the first edition. 
I'm not sure I will ever consider this project as "done", however.

The book is best read as a downloaded PDF file, which can be found 
[in the GitHub releases](https://github.com/briantoby/PowderCrystallography/releases/latest) for this repo; look for the .pdf file there. 
There is also an HTML version of the book that was generated more for machine-learning applications than humans, and is
not as well formatted as the PDF, but if you really want to see the same material broken up into a few hundred short web pages,
[start here](https://briantoby.github.io/PowderCrystallography/HTML-template.html).

Comments, corrections, and questions on the text are welcomed, preferably as 
[GitHub Issues](https://github.com/briantoby/PowderCrystallography/issues) or in the 
[Discussions](https://github.com/briantoby/PowderCrystallography/discussions). If you don't
want to sign up for a free GitHub account, you can track down how to e-mail me.
